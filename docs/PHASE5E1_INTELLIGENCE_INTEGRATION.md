# Phase 5E.1 — Full Intelligence Outreach Integration

## Overview

Phase 5E.1 upgrades Research Letters to draw from **all 5 intelligence sources** the platform generates, replacing the simple personalisation score with a Research Utilization Score and a quality checklist.

---

## How Intelligence Powers Outreach

When a user opens Research Letters and selects a target + product, the page automatically loads intelligence from every available source and injects it into the generated letters.

### Intelligence Sources

| Source | Data Used | Where It Comes From |
|--------|-----------|---------------------|
| **Product Intelligence** | Market position, campaign opportunity, outreach angle, buyer persona | `generateProductIntelligence()` — deterministic, runs client-side from product fields |
| **Partner Strategy** | Top partner category, revenue opportunity, recommended deal type, category-specific outreach angle | `generatePartnerIntelligence()` — deterministic, runs client-side |
| **Qualification Engine** | Partner fit score (0–100), qualification label, score reasons (audience match, content relevance, partnership readiness), hard flags, next best action | `GET /qualification/queue?productId=…` — matched to target by name |
| **Contact Intelligence** | Business email, contact readiness score (0–100), preferred contact method, verification status | `GET /contact-intelligence?productId=…` — matched to target via prospect ID |
| **Outreach History** | Prior message count, prior statuses, last outreach date | `GET /outreach-operations?productId=…` — filtered by targetId |

---

## OutreachIntelligenceContext

The `OutreachIntelligenceContext` type (`partnerOutreach.ts`) is the central aggregation object:

```ts
interface OutreachIntelligenceContext {
  // Creator / Target
  targetName, company, platform, partnerCategory, website, socialUrl
  // Manual research notes (editable inline)
  audienceSize, contentAngle, notes
  // Product intelligence
  productName, productCategory, productSummary, productBenefits
  productMarket, productOutreachAngle
  // Partner strategy
  partnerStrategySummary, recommendedDealType, strategyOutreachAngle
  // Qualification engine
  partnerFitScore, qualificationLabel, qualificationReasons[]
  hardFlags[], nextBestAction
  // Contact intelligence
  contactReadinessScore, preferredContactMethod, businessEmail
  // Outreach history
  priorOutreachCount, priorOutreachStatuses[], lastOutreachDate
  // Discovery / YouTube
  latestVideoTitle, latestVideoDate
}
```

## Research Utilization Score

Replaces the old simple personalisation score. Scored out of **100 total** across 5 dimensions:

| Dimension | Max | Driven By |
|-----------|-----|-----------|
| Product Context | 20 | Product name, category, market, summary, outreach angle |
| Creator Context | 20 | Target name, company, audience size, content angle, latest video |
| Qualification Context | 20 | Fit score, qualification label, score reasons |
| Contact Context | 20 | Contact readiness score, business email, preferred method |
| Strategy Context | 20 | Strategy summary, outreach angle, recommended deal type |

Score labels:
- **80–100%** — Rich intelligence
- **50–79%** — Moderate — add more sources
- **20–49%** — Basic — run qualification
- **0–19%** — No intelligence yet

---

## Quality Checklist

8 items displayed alongside the score:

1. Product referenced in letter *(product)*
2. Creator referenced by name *(creator)*
3. Audience size referenced *(creator)*
4. Content angle or latest video used *(creator)*
5. Qualification reason referenced *(qualification)*
6. Strategy outreach angle applied *(strategy)*
7. Contact method aligned *(contact)*
8. CTA included *(product)*

## Intelligence Panel

The **Intelligence Sources** card in the left column shows the status of each source:

- ✅ **Loaded** — green, shows summary data
- ⚠️ **Partial** — amber, some data missing
- ○ **Missing** — grey, links to the relevant page to generate that intelligence

## Letter Generation Logic

Letters are generated by `generateIntelligenceOutreachMessages()` in `partnerOutreach.ts`, which uses the `OutreachIntelligenceContext` to:

### First Email
- Uses qualification reasons (if available) for the "why selected specifically" section
- Falls back to strategy angle → content angle → generic category-fit
- Adds audience hook if audienceSize is present
- References latest video or content angle inline
- Adds qualification label + fit score signal if score ≥ 60
- Adds strategy-specific outreach angle as a "How I'd suggest we work together" section
- References prior outreach history if applicable

### Short DM
- Personal opener using qualification label if available
- Audience size hook
- Content/video reference for instant credibility
- Qualification signal if strong

### Follow-up 1
- Restates fit score as a credibility hook
- Family-specific social proof example

### Follow-up 2
- Includes strategy angle in body if available

### Handle Objections
- References qualification label and fit score to counter "not the right fit" objection

## Matching Logic

The platform matches qualification data and contact intelligence to the selected target using a name-based best-effort match:

```
target.name (lowercase) === prospect.name (lowercase)
OR
prospect.name includes target firstName (≥3 chars)
```

This works because targets are created by approving qualified prospects (same name). If no match is found, those intelligence sources show as "Missing" in the panel.

## Limitations

- **Name-based matching** — Qualification and contact intel are matched to targets by name. If a target was added manually (not via the qualification approval flow), no qualification/contact match will be found.
- **No latestVideoDate** — Set to `null` in Phase 5E.1. Would require a YouTube API call or the prospect's YouTube discovery data to be populated.
- **latestVideoTitle** — Extracted from the matched prospect's notes field via regex pattern (`/latest.*?:\s*(.+?)(?:\n|$)/i`). Populated when the prospect was discovered via YouTube search and the title was stored in notes.
- **Contact intelligence is product-scoped** — All contact intel for the selected product is fetched; then matched by prospectId from the qualification match. If a creator has contact intel from a different product run, it won't be found.
- **No performance data in context** — Campaign/creator performance data is not yet included in `OutreachIntelligenceContext`. This is Phase 5E.2 territory.
